# Requisitos adicionais da organização

Este ficheiro existe para receber requisitos que cheguem depois do arranque do projeto.
Cada requisito entra aqui **antes** de ser implementado, com o impacto e o marco onde encaixa.

Última atualização: 2026-11-14 · sem requisitos adicionais recebidos até à data.

## Como registar

1. Copiar a linha do modelo para a tabela.
2. Escrever o requisito com as palavras da organização, sem interpretar.
3. Marcar o impacto: interface, dados, motor, PWA, texto ou submissão.
4. Indicar o marco (`1`–`6`) ou `fora de âmbito` com a razão.
5. Se o requisito exigir dados que não temos, acrescentar `TODO_FONTE` e a fonte em falta.

## Decisões que não mudam sem discussão

- Nenhum número no ecrã sem etiqueta de origem.
- Nenhum dado inventado: `TODO_FACTO` / `TODO_FONTE` em vez de estimativas apresentadas como factos.
- Sem contas, sem backend e sem recolha de dados pessoais na versão principal.
- Sem imagens de pessoas, sem vozes de menores, sem promoção comercial.
- Recursos do desafio limitados aos EUA (WSS, CDL, PRISM, SSURGO, NAIP) não são usados para Angola.
